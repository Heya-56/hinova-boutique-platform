# Préparation ISO/IEC 27001 — mesures techniques et preuves

ISO 27001 certifie l'**organisation** (système de management de la sécurité de l'information, SMSI), pas le code. Ce tableau relie les mesures déjà en place dans la plateforme aux thèmes de l'Annexe A, pour constituer le dossier de preuves. Les intitulés sont résumés ; la correspondance exacte est à valider avec l'auditeur.

| Thème | Mesure en place | Preuve |
|---|---|---|
| Contrôle d'accès | Séparation application / vitrines, rôles commerçant / admin, isolation par boutique dans chaque requête | `test/separation.sh`, `test/smoke.sh` (accès croisés refusés) |
| Authentification | Mots de passe PBKDF2-SHA256 salés, sessions signées HMAC, cookies HttpOnly/Secure/SameSite | `src/lib.js`, tests « cookie falsifié refusé » |
| Cryptographie | HTTPS, sauvegardes chiffrées AES-256, empreinte HMAC des IP (essais) | `scripts/sauvegarde.sh`, migration 0006 |
| Journalisation | `journal_audit`, `paiements_evenements` (idempotence) | Migration 0004 |
| Sauvegarde | Export quotidien vérifié et chiffré vers OVHcloud (France) | `docs/DEPLOIEMENT_OVH.md` |
| Fournisseurs | Cloudflare, Stripe, Brevo, OVHcloud : registre des sous-traitants et DPA à signer | À faire (juriste) |
| Données personnelles | Minimisation, pièces OSB privées, image du générateur jamais stockée, attestation de titularité | `docs/CONFORMITE.md` |
| Développement sécurisé | Revue de code, tests automatiques avant chaque livraison, aucun secret dans le dépôt | Historique Git, `docs/SECURITY.md` |

## À produire côté organisation
Politique de sécurité, analyse des risques, déclaration d'applicabilité, procédure de gestion des incidents, plan de continuité, revue de direction, audit interne.
